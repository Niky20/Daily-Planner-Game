# Quest Day

A cozy, fantasy-inspired daily planner that turns everyday habits into quests. Add your own activities, check them off, then claim each reward to earn XP and gold. Keep a daily streak to build momentum, level up, and collect milestones with Lumi, your elf ranger companion.

## Features

- Create, edit, and remove daily quests with a category, time, and XP reward.
- Complete a quest and claim its reward in a separate step, with a confetti celebration.
- Track current and longest streaks, level progress, earned XP, and gold.
- Lose 20% of banked XP when a streak is broken and you begin a new one.
- Save progress in the browser with local storage; no account is required.
- Use the responsive dashboard on desktop, tablet, or phone.

## Run locally

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
